# Wish Refiner · 愿望精确改写

把一句“我想……”，写成一份结果明确、边界清楚、尽量不留歧义的愿望。

适合许愿、祈愿、求神拜佛时整理心意，也适合喜欢“愿望契约”风格的人：既说明自己想得到什么，也说明不接受怎样的实现方式与代价。

## 从一句话开始

```text
用 $wish-refiner 改写：我想找到高薪工作。
```

输出示例（简短版）：

> 我希望在「待填：期限」内，获得一份我符合任职条件、能够胜任且自愿从事的工作，固定税后月薪不低于「待填：金额及币种」。薪资应对应明确、合理的正常工作时间，不得将不保证发放的奖金、提成、股权估值或报销款计入固定月薪，制造高薪的表象。
>
> 我希望获得真实有效的录用、实际入职并正常履职，岗位职责、薪酬、工作时间和地点均在入职前明确，并落实为合法有效的书面约定；薪酬能够按约定及时、足额支付，不得仅以口头承诺、虚假通知或无法兑现的合同代替。
>
> 获得和从事这份工作，不依靠欺骗、违法或侵害他人权益，不以损害健康、自由、重要关系或未来正常发展机会为代价，也不附带未告知、未同意的债务、交换条件或非正常束缚。我仍保有依法离职和自主选择职业道路的权利。
>
> 最终结果应是：现实中的我，真实拥有一份薪酬达到目标、待遇能够兑现且适合自己的工作，并由此获得更充足的经济保障、合理的生活空间和符合自身意愿的职业选择。

金额、期限等关键条件由你决定。信息不足时，技能会简短追问或保留待填项，不会擅自把“发财”解释成“72 小时内获得一亿元”。

## 它会写清楚什么

| 维度 | 要解决的问题 |
| --- | --- |
| 核心结果 | 想获得什么，什么时候实现，达到什么程度？ |
| 完成标准 | 怎样才算真实实现，而不是名义拥有或短暂体验？ |
| 实现方式 | 哪些来源、程序和手段可以接受？ |
| 代价边界 | 哪些伤害、隐藏义务或未来牺牲不能接受？ |
| 自主选择 | 实现后是否仍能独立判断、自由使用或改变决定？ |
| 条款一致性 | 有没有相互冲突、过度约束或违背本意的表述？ |

默认使用第一人称，输出四至七段左右的完整愿望正文。篇幅随实际歧义调整，也可以指定简短、口语或祷告式表达。

## 安装

这是一个 Codex skill，以 Markdown 指令为核心，无需运行项目代码或安装额外依赖。

下载或克隆本仓库，将包含 `SKILL.md` 和 `agents/` 的目录以 `wish-refiner` 为名称放入个人技能目录：

- 已设置 `CODEX_HOME`：放入 `$CODEX_HOME/skills/wish-refiner/`。
- 未设置 `CODEX_HOME`：放入 `~/.codex/skills/wish-refiner/`。
- Windows 默认路径：`%USERPROFILE%\.codex\skills\wish-refiner\`。

安装后的目录结构：

```text
skills/
└── wish-refiner/
    ├── SKILL.md
    ├── README.md
    └── agents/
        └── openai.yaml
```

`SKILL.md` 包含改写规则，`agents/openai.yaml` 提供技能的显示名称和默认调用提示。

## 使用示例

直接发送愿望：

```text
用 $wish-refiner 改写：我想发财。
用 $wish-refiner 改写：我想考上公务员。
用 $wish-refiner 改写：我想找到女朋友。
用 $wish-refiner 改写：我想找到高薪工作。
```

补充具体条件，结果会更贴合你的意思：

```text
用 $wish-refiner 改写：我想在半年内找到上海的工作，
固定税后月薪至少 2 万元人民币，接受混合办公，不接受长期过度加班。
```

也可以控制输出风格：

```text
用 $wish-refiner 改写：我想发财。完整防漏洞版。
用 $wish-refiner 改写：我想考上公务员。简短一点。
用 $wish-refiner 改写：我想找到女朋友。语气温柔，保留双方自由意志。
用 $wish-refiner 改写：我想找到高薪工作。直接输出，缺少参数用待填项。
```

## 改写原则

- **保留本意**：不替你决定金额、期限、伴侣特征或人生目标。
- **针对具体愿望**：财富关注真实可支配资产，工作关注实际入职和待遇兑现，感情关注双方真实、自愿的关系。
- **避免字面满足**：排除梦境、幻觉、虚假记录、身份替换和名义所有等违背本意的结果。
- **保护自主意愿**：感情愿望不把操控他人、剥夺拒绝或离开的能力写成成功。
- **检查矛盾**：例如，获得新财富会改变现实状态，因此不会同时要求“世界完全不变”。
- **按需表达**：不机械堆叠所有风险，也不擅自添加宗教对象、仪式或交换承诺。

## 关于这份技能

这是一个愿望文本改写工具。它尊重宗教、祈愿和想象性表达；措辞的精确性不构成愿望必然实现的保证，生成文本也不具有法律协议的效力。

如果你想调整默认风格、篇幅或边界，可以修改 [SKILL.md](SKILL.md) 中的规则。
